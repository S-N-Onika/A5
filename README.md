1️⃣ What is the difference between var, let, and const?

ANSWER:
var, let and const are used for variable declaration .

var - variable can be re-declare . value can be changed . function scoped. but we should not use it .

let - variable can't be re-declare . value can be changed . block scoped.

const - variable can't be re-declare . value can't be changed . block scoped.

2️⃣ What is the spread operator (...)?

ANSWER:
Spread Operator -

1. It expands an array into another.
2. Merges  array
3. Spreads array as function arguments.
4. Copy or merges objects
5. Last value gets priority

Spread Operator is written with (...).

3️⃣ What is the difference between map(), filter(), and forEach()?

ANSWER:

map() - Looping through array and returning a new array

filter() - Selecting some elements with a condition

forEach() - Looping through array but not returning a new array

4️⃣ What is an arrow function?

ANSWER:

Arrow function -
Arrow functions can be used to shorten functions. If the function is multi-line, return must be used. If it is a single line function, return must not be used.
